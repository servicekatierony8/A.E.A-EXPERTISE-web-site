================================================

------------------

                      services en cartes, référence Yamoussoukro, méthode)
- cabinet.html      : Le Cabinet (présentation, crédibilité, piliers,

                      d'Abidjan), galerie plein écran, formulaire WhatsApp
- assets/images/    : 13 photos d'illustration + logo officiel du cabinet

DESIGN
------
Identité « cabinet premium » : vert très foncé, ivoire et doré,
titres en Playfair Display. Site 100 % statique : aucun serveur,
aucune base de données, aucun coût d'hébergement obligatoire.

DÉPLOIEMENT SUR CLOUDFLARE (workers.dev / Pages)
------------------------------------------------
Option A — Glisser-déposer (la plus simple) :
  1. Compresser le CONTENU de ce dossier (ou utiliser le zip fourni).
  2. Cloudflare → Workers & Pages → Create → Pages → Upload assets.
  3. Glisser le zip, valider : le site est en ligne en moins d'une minute.

Option B — Depuis GitHub (déploiement automatique à chaque modification) :
  1. Pousser le contenu de ce dossier à la racine du dépôt GitHub
     du site A.E.A.
  2. Cloudflare → Workers & Pages → Create → Pages → Connect to Git.
  3. Choisir le dépôt, framework « None », dossier de sortie « / » (racine).
  4. Chaque push sur le dépôt met le site à jour automatiquement.
